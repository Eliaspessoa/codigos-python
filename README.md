# Exercícios de Lógica em Python

Este repositório contém uma coleção de exercícios práticos de lógica de programação desenvolvidos durante meus estudos em **Análise e Desenvolvimento de Sistemas (ADS)**.

## Projetos inclusos:

- **Exercícios anteriores**: Scripts de prática de lógica básica.
