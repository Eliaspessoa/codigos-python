# 🐍 Jornada de Estudos em Python

Repositório dedicado à minha evolução e prática na linguagem **Python**. Aqui centralizo os exercícios práticos, desafios e projetos desenvolvidos durante meus estudos de programação e na faculdade de **Análise e Desenvolvimento de Sistemas (ADS)**.

O objetivo deste espaço é consolidar a lógica de programação, estruturas de dados e automação, construindo uma base técnica sólida para o desenvolvimento de software.

---

## 📂 Estrutura do Repositório

O repositório está organizado em módulos progressivos de aprendizagem:

*   **Fundamentos:** Variáveis, tipos de dados, operadores aritméticos e manipulação básica de strings.
*   **Estruturas de Controle:** Condicionais (`if`, `elif`, `else`) e estruturas de repetição (`for`, `while`).
*   **Estruturas Compostas:** Manipulação de tuplas, listas, dicionários e conjuntos.
*   **Projetos Práticos e Mini-sistemas:** Scripts interativos, simuladores e aplicações de console voltadas para resolução de problemas reais.

---

## 🚀 Tecnologias e Conceitos Aplicados

*   **Linguagem:** Python 3
*   **Conceitos de Lógica:** Algoritmos, laços aninhados, validação de entradas, tratamento de fluxo e modularização.
*   **Controle de Versão:** Git e GitHub (gestão de histórico de código e versionamento).
